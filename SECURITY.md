# Security Policy

CCRouter is currently a pre-release project. No version is yet covered by a
long-term security support commitment.

Report suspected vulnerabilities through GitHub's private vulnerability
reporting flow for this repository. Do not include credentials, private source
code, production URIs, access tokens, signing material, or user data in a
public issue.

For ordinary bugs that do not contain sensitive information, use the public
issue tracker. A future stable release will document its supported version
window and response policy before publication.
